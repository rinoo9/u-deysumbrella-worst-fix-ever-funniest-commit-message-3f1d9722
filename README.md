# Worst Fix Ever: Funniest Commit Message

Entry for the [make.fun](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722) bounty "Worst Fix Ever: Funniest Commit Message".

`main.py` writes one commit message (at most 100 characters) for a bug fix
that made everything worse to `/output/entry.txt`:

> fix: slow page load by serving a blank page; loads instantly now

Run it with:

```sh
python3 main.py
```
